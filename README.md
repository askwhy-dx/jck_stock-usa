# stock-usa — 미국 주식 스캐너

국내 단테의 **🎯 손익비 돌파**와 **🍚 밥그릇3** 전략으로 미국 주식을 매일 찾아 주는 도구입니다.

- 시세·일봉: **토스증권 Open API**
- 재무·공시: **SEC EDGAR API** (미국 증권거래위원회 공식 · 무료)
- 주문: 사람이 직접 (자동 주문 없음)

## 2. 처음 설정

1. **토스 키** — 토스증권 WTS > 설정 > Open API 에서 발급 → `.env` 에 입력
   ```
   TOSS_CLIENT_ID=...
   TOSS_CLIENT_SECRET=...
   TOSS_ACCOUNT_SEQ=...      # python check.py 로 확인
   SEC_USER_AGENT=이름 이메일  # SEC 가 연락처를 요구함
   ```
2. **허용 IP 등록** — 같은 화면의 「허용 IP 관리」에 이 PC 의 공인 IP 등록 (현재 `61.36.60.229`). 다른 망에서는 403 으로 막힘
3. **연결 확인** — `python check.py` → 「토큰 OK · 환율 · 계좌 · 보유주식 조회 OK」

## 3. 실행

```
python fetch_us.py     # 일봉 갱신

```

## 4. 전략 정의

### 🎯 손익비 돌파 — 국내 `stock/screen_rr_breakout.py` 와 동일

| 구분 | 조건 |
|---|---|
| 신호 (최근 15거래일) | 전날 종가 ≤ 돌파선, 당일 종가 > 돌파선 (돌파선 = max(MA112, MA224)) · 양봉 · 거래량 ≥ 20일 평균 2배 · 시총 ≥ 1,000억 원 |
| 통과 (전일 확정봉) | 종가 > 돌파선 · 손절 폭 2~5% (손절 = 돌파선 × 0.99) · 양봉 · 신호 봉 몸통 ≥ 50% |
| 과거 유사 사례 | 2022년~ 전 종목에서 신호 봉 모양(몸통·윗꼬리·거래량 배수·등락)이 같은 사례 30건 이상, 기대값 > 0 (60일 안에 +10% 먼저 = 승, 손절 먼저 = 패) |
| 공시 | 올해 악재 공시 있으면 제외 |
| 재무 | 참고 배지만 (제외하지 않음) |

### 🍚 밥그릇3 — 국내 `stock/screen_bowl3_quality.py --no-pullback` 방식

| 구분 | 조건 |
|---|---|
| 대상 (돌파 풀) | 2026-06-10 이후 처음 112·224선을 돌파한 날 등락 +10%↑ · 거래량 3배↑ · 점수 80↑ · 시총 1,000억 원↑. 그 뒤 +10%(졸업)도 돌파선 이탈도 안 한 종목 |
| 재무 | 3개 회계연도 연속 상승 (아래 5절) |
| 공시 | 올해 악재 공시 0건 |

### 분할매수 계산식 — 국내 대시보드(`stock/auto_intake.js`)와 동일

선정된 종목마다 결과에 붙습니다. 정해 둔 계산식의 결과이며 투자 권유가 아닙니다.

| 항목 | 정하는 방법 |
|---|---|
| 지지선 | max(MA112, MA224). 1~3차 간격이 안 나오면 그 아래 이평·직전 저점 |
| 손절 | 지지선 × 0.99 (종가 기준) |
| 1차 / 3차 | min(현재가, 지지선 × 1.04) / 손절 ÷ 0.98 |
| 2차 | 1차에서 3차 쪽으로 40% (1차 −2%보다 낮지 않게) |
| 비중 | 1 : 1 : 2 |
| 목표 | 평단 +8~15% 안의 과거 고점, 없으면 +5% 넘는 가장 가까운 고점 |
| 보류 표시 | 손익비 < 1.5, 또는 목표 ≤ 현재가(1차까지 내려오길 대기) |

🎯 손익비 전략의 목표(+10% 고정)와 다릅니다. 분할매수 목표는 실제 저항이라 저항이 가까우면 손익비가 낮게 나옵니다.

### 국내와 다른 점

| 항목 | 국내 | 미국 |
|---|---|---|
| 재무·공시 | DART | SEC |
| 시가총액 | KRX 그날 값 | 현재 발행주식수 × 그날 종가 × 오늘 환율 (근사) |
| 밥그릇3 대상 | 돌파 풀 + 눌림 풀 | 돌파 풀만 |
| 악재 공시 | 유증·CB·BW·감자·횡령·관리·상폐·감사부적정 | 공모(S-1·F-1·424B4)·사모 발행(8-K 3.02)·상장기준 미달(8-K 3.01)·상장폐지(Form 25)·보고 지연(NT 10-K 등)·재무제표 신뢰불가(8-K 4.02)·파산(8-K 1.03)·**인수합병 진행** |

**인수합병을 넣은 이유:** 미국은 인수 발표일에 주가가 급등하고 거래량이 터져서 돌파로 잡힙니다. 그 뒤 인수가에 묶여 졸업도 이탈도 하지 않아 돌파 풀에 계속 남습니다. 첫 스캔에서 밥그릇3 통과 7종 중 5종이 이런 종목이었습니다.

## 8. 알려진 한계

- **해외 기업**: SEC 재무가 1년 늦을 수 있고, 8-K 대신 6-K 를 내서 공시를 자동 판정할 수 없음 → 「재무 미반영」·「공시 미확인」 표시 예정. 토스 화면으로 확인 필요
- **과거 사례**: 지금 상장된 종목만 포함 (상장폐지 종목 없음)
- **기대값**: 미국 손익비 전체 기대값은 +0.02%로 국내(+0.13%)보다 낮음. 같은 손절·목표(+10%) 구조가 미국에 덜 맞을 수 있음
- **토큰**: 클라이언트당 1개만 유효해서 스크립트 2개를 동시에 돌리면 서로 끊김
- **실계좌**: 모의투자가 없어서 주문 API 는 쓰지 않음
- **은행 매출**: SEC 매출 항목이 은행엔 일부만 잡힘 (COLB 매출 1.77억 < 순이익 5.5억 달러) → 은행의 「3년 성장」 배지는 참고만
- **적자 축소**: 순이익 적자가 줄어도 「증가」로 통과 (NRXS)
